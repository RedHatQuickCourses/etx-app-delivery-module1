== How Red Hat OpenShift Delivers an Application Platform

* *Red Hat OpenShift* builds on Kubernetes by integrating the capabilities required to support the complete application lifecycle.

* Rather than requiring organizations to assemble and maintain independent products, OpenShift provides a unified platform that includes developer tools, application runtimes, build services, CI/CD, GitOps, security, AI capabilities, and hybrid cloud support.

=== OpenShift Capability Map

At the foundation, *Red Hat Enterprise Linux* provides the operating system, while *Kubernetes* delivers container orchestration and workload management.

OpenShift extends this foundation by integrating capabilities for:

* Application development
* Application builds
* CI/CD and GitOps
* Serverless
* Service Mesh
* Developer tools
* Internal Developer Platforms
* Security
* AI services
* Multicluster and hybrid cloud management

Together, these capabilities provide a consistent platform for building, deploying, securing, and operating applications across on-premises, public cloud, private cloud, virtualized environments, and edge locations.
