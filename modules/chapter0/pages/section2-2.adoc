= Why an Application Platform?
:navtitle: Why and What is Application Platform?

* Many organizations begin with a managed Kubernetes service.
* They soon realize that Kubernetes alone doesn't provide everything required for enterprise software delivery.
* Teams must separately integrate CI/CD tools, container registries, observability, service mesh, security solutions, developer tools, and identity services.
* Managing each of these independently increases operational complexity.
* An Application Platform simplifies this by providing these capabilities as an integrated platform.

== What is an Application Platform?

* An *Application Platform* is a unified set of capabilities that enables organizations to build, deliver, secure, and operate modern applications throughout the software development lifecycle.
+
image::app.png[align="center", height="600", width="800"]
+
.Application Build: (Click here to expand)
[%collapsible]
====
* Application Build provides the capabilities developers need to design, develop, modernize, and package applications for deployment.
* It includes application runtimes, developer tools, serverless capabilities, cloud service integrations, and migration tools that simplify application development.
* By providing standardized development environments and integrated tooling, developers can build applications more efficiently while following consistent engineering practices.
====

+
.Application Delivery: (Click here to expand)
[%collapsible]
====
* Application Delivery focuses on automating how applications are built, deployed, monitored, and managed across development, testing, and production environments.
* It includes capabilities such as CI/CD pipelines, GitOps, container registries, observability, logging, and virtual machine support.
* These capabilities enable organizations to deliver applications faster, improve deployment consistency, and simplify ongoing operations.
====

+
.Application Security: (Click here to expand)
[%collapsible]
====
* Application Security integrates security throughout the software delivery lifecycle rather than treating it as a separate activity.
* It includes capabilities such as service mesh, vulnerability scanning, security policy enforcement, certificate and secret management, and authentication with Single Sign-On (SSO).
* By embedding security into every stage of development and deployment, organizations can deliver applications that are secure, compliant, and enterprise-ready.
====

* Rather than integrating and managing these capabilities individually, an *Application Platform* delivers them as a unified platform, enabling developers to focus on building applications while the platform provides the services required to develop, deploy, secure, and operate them consistently.


== How does Red Hat OpenShift deliver Application Platform capabilities?

* Red Hat OpenShift includes much more than Kubernetes.

* It provides integrated runtimes, build services, CI/CD pipelines, GitOps, service mesh, developer tools, internal developer portals, security capabilities, AI services, and hybrid cloud deployment options.
+
image::map.png[align="center", height="800", width="800"]
+
.Above diagram illustrates how OpenShift delivers the capabilities of a modern Application Platform (Click here to expand)
[%collapsible]
====
* Starting with Red Hat Enterprise Linux as the operating system foundation, Kubernetes provides container orchestration and workload management. 
* OpenShift then builds on Kubernetes by adding application platform capabilities such as application runtimes, builds, CI/CD pipelines, GitOps, Serverless, Service Mesh, and developer tools, enabling organizations to build, deploy, and manage applications throughout their entire lifecycle. 
* Additional capabilities, including Developer Hub, advanced security, multicluster management, middleware, and AI services, extend the platform to meet enterprise needs. 
* Most importantly, these capabilities are available consistently across physical infrastructure, virtual environments, private and public clouds, and edge deployments, providing developers with a unified application delivery experience regardless of where applications run.
====

.Key Takeaway
[NOTE]
====
An Application Platform is more than Kubernetes. It combines application development, delivery, security, and operational capabilities into a unified platform that enables developers to focus on building applications instead of integrating infrastructure and tools.
====
