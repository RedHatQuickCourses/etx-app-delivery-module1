Introduction to Application Platforms and Platform Engineering

Introduction

Welcome to this quick course on the Introduction to Application Platforms and Platform Engineering. This course is the first in a series of six courses about Application Platform Delivery:

  • Introduction to Application Platforms and Platform Engineering (This course)

  • Software Factory Foundations with OpenShift Dev Spaces

  • Software Delivery with OpenShift Pipelines and GitOps

  • DevEx with Red Hat Developer Hub

  • Application Modernization with MTA

  • Trusted Software Supply Chain (TSSC) (Coming soon)

What’s in this course?

This course introduces Platform Engineering and Application Platforms, covering the evolution from DevOps to Platform Engineering, the role of Kubernetes and Application Platforms, how Red Hat OpenShift delivers an integrated platform, and the key roles involved in modern application delivery.

Duration: 30 minutes

Objectives

By the end of this module, you will be able to:

  • Explain how software delivery evolved from DevOps to SRE and Platform Engineering.

  • Describe the purpose and value of an Application Platform.

  • Explain why Kubernetes alone is not sufficient for modern application delivery.

  • Distinguish between a Container Management Platform and an Application Platform.

  • Identify the key capabilities of a modern Application Platform, including application runtimes, builds, CI/CD, observability, security, and developer self-service.

  • Describe how Red Hat OpenShift extends Kubernetes to provide an integrated Application Platform.

  • Explain the roles and responsibilities of Operations Engineers, Platform Engineers, and Application Developers.

  • Apply an Application Platform litmus test to evaluate whether a platform provides the capabilities and developer experience required for modern software delivery.
